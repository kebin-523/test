# 깃 허브 사용 첫번째

## 한 번만
git init : 연결

## 여러 번
git add README.md : README.md 파일 추가
git add . : 모든 파일 추가
git commit -m "first commit" : 주석

## 한 번만
git remote add origin https://github.com/kebin-523/test.git

## 한 번만
git branch -M main : branch 이름 설정 -> main 대신 다른 이름 사용 가능

## 여러 번
git push -u origin main : main = branch 이름
