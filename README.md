# 클래스로(Classro) 회사 소개 웹사이트

동네 공방·작업실의 원데이 클래스(도자기, 베이킹, 가죽공예, 플라워, 드로잉, 향수)를 앱에서 찾고 바로 예약·결제하는 서비스 **클래스로**의 소개 페이지입니다.
`00_회사소개.md` 내용을 기준으로 만들었습니다.

> 수업용 가상 회사입니다. 등장하는 회사·인물·수치는 모두 지어낸 것입니다.

## 폴더 구조

```
test/
├─ index.html        # 메인 페이지
├─ css/
│  └─ style.css      # 스타일 (반응형)
├─ js/
│  └─ main.js        # 메뉴, 스크롤 효과, 숫자 카운트업
├─ 00_회사소개.md    # 원본 자료
└─ README.md
```

## 실행 방법

빌드 과정 없이 `index.html`을 브라우저에서 열면 됩니다.
폰트(Noto Sans KR)는 Google Fonts에서 불러오므로 인터넷 연결이 필요합니다.

## 페이지 구성

| 섹션 | 내용 |
| --- | --- |
| 히어로 | 서비스 한 줄 소개, 클래스 종류 |
| 소개 | 한 줄 소개 |
| 기본 정보 | 핵심 수치, 기본 정보 표, 지역별 제휴 공방 분포 |
| 핵심 사용자 흐름 | 방문 → 예약 완료 6단계 |
| 분기 목표 | 2026년 4분기 목표 3가지 |
| 최근 소식 | 타임라인 |
| 팀별 고민 | 개발·디자인·PO·마케팅 |
| 키트 파일 | 실습 자료 목록 |

## 주요 기능

- 모바일·태블릿·데스크톱 반응형 레이아웃
- 스크롤 시 섹션 등장 효과와 숫자 카운트업
- 현재 섹션을 메뉴에서 강조
- 모바일 햄버거 메뉴
- `prefers-reduced-motion` 설정 시 애니메이션 최소화
